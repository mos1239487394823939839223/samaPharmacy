KEY FEATURES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✓ Sales Management
  - Barcode scanning with layout-independent detection
  - Shopping cart with quantity adjustment
  - Cash & credit payment tracking

✓ Inventory Tracking
  - Item database with multiple barcodes per item
  - Batch/expiry date management (FEFO)
  - Real-time stock status

✓ Hardware Integration
  - USB HID Barcode Scanner (G1–G5 guards)
  - ESC/POS Thermal Printer (P1–P10 guards)
  - Cash Drawer (auto-test pin detection)
  - Arabic Receipt Printing (raster)

✓ Multi-Language
  - Arabic & English UI
  - RTL layout support
  - Arabic invoice printing

✓ Data Persistence
  - SQLite database (offline-first)
  - Print queue persistence
  - WAL mode for reliability

HARDWARE GUARDS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Scanner (src/hardware/scanner.ts):
  G1  Arabic contamination detection & repair
  G2  Prefix-capture watchdog (release keyboard if stuck)
  G3  Idle flush (scanners with no terminator)
  G4  IME & auto-repeat suppression
  G5  Diagnostics & self-test

Printer (src/hardware/escpos-printer.ts):
  P1  Blank & inverted receipt detection
  P2  Oversize receipt prevention (4000-row limit)
  P3  Arabic font verification
  P4  Rasterise timeout + single-flight lock
  P5  Paper-out probe (network transport)
  P6  Drawer pin fallback (test both pin 2 & 5)
  P7  Attempt cap + dead-letter queue (max 5 retries)
  P8  Atomic queue persistence
  P9  Transaction safety (no printing in DB tx)
  P10 ASCII fallback receipt

DATABASE SCHEMA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Tables:
  items            Product master (id, name, nameAr, category)
  barcodes         Multiple barcodes per item
  batches          Stock tracking (itemId, expiryDate, quantity)
  invoices         Sales/purchase records (serial, type, total)
  invoiceLines     Line items with batch reference
  customers        Credit customer records (creditLimit, outstanding)
  users            Staff accounts (role, permissions)

Location:
  ~/.config/sama-pharmacy/pharmacy.db (Linux/macOS)
  %APPDATA%\Roaming\sama-pharmacy\pharmacy.db (Windows)

COMMON TASKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Screen Development:
  1. Create src/renderer/screens/MyScreen.tsx
  2. Add to AppState.currentScreen type union
  3. Handle in Layout.tsx menu & App.tsx render()

Adding IPC Handler:
  1. Define handler in src/main/ipc.ts
  2. Expose in preload.ts via contextBridge
  3. Call from renderer: window.electronAPI.<name>()

Database Query:
  1. Add function to src/main/database.ts
  2. Wrap in IPC handler if needed
  3. Subscribe in renderer via store

TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Scanner not detecting:
  → Settings → Hardware → Scanner diagnostics
  → Check median interval, contamination counter, watchdog resets

Printer not printing:
  → Settings → Hardware → Test Printer
  → Check paper status, network connectivity, font loading

Invoice not saving:
  → Check database file exists & has write permission
  → Verify no transaction guard violations (P9)
  → Check disk space

See QUICKSTART.md § Troubleshooting for detailed steps.
