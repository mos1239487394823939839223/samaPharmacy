🔐 SAFETY GUARDS (THE DIFFERENCE BETWEEN "IT WORKS" AND "IT WORKS RELIABLY")
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SCANNER GUARDS (prevents barcode misreads):
  G1  Arabic contamination detection & repair
  G2  Prefix capture watchdog (release stuck keyboard)
  G3  Idle flush (scanners with no terminator)
  G4  IME & auto-repeat suppression
  G5  Diagnostics with self-test

PRINTER GUARDS (prevents paper waste and silent failures):
  P1  Blank & inverted receipt detection
  P2  Oversize receipt prevention (4000-row limit)
  P3  Arabic font verification
  P4  Rasterise timeout + single-flight window
  P5  Paper-out probe (network transport)
  P6  Drawer pin fallback (tests both pins)
  P7  Attempt cap + dead-letter queue (max 5 retries)
  P8  Atomic queue persistence (crash-safe)
  P9  Transaction safety (no printing in DB tx)
  P10 ASCII fallback receipt (when raster fails repeatedly)

⚠️  IMPORTANT CONFIGURATION BEFORE FIRST USE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. SCANNER
   • Program with F9 prefix (use your scanner manual)
   • Set terminator to Enter
   • Verify in Settings → Hardware → Scanner Diagnostics

2. PRINTER
   • Get network IP or share name
   • Test connection: ping 192.168.1.50 (or your IP)
   • Configure in Settings → Hardware → Printer
   • Test: Settings → Hardware → Test Printer

3. CASH DRAWER
   • Identify which pin it's on (2 or 5)
   • Set Drawer Pin in Settings
   • Test: Settings → Hardware → Test Printer (drawer opens after test)

4. DATABASE
   • Verify write access to ~/.config/sama-pharmacy/
   • Database file will be created on first startup

🐛 TROUBLESHOOTING FLOWCHART
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Scanner not working?
├─ Is it connected via USB?
├─ Go to Settings → Hardware → Scanner
├─ Check Arabic contamination counter
│  └─ If > 0: Something bypassed event.code. Find and fix.
├─ Check watchdog resets
│  └─ If > 0: Terminator not configured. Set to Enter.
└─ Run Test Scanner → scan a barcode

Printer not printing?
├─ Is it powered on?
├─ Go to Settings → Hardware → Printer
├─ Check "reachable" status
│  └─ If False: ping 192.168.1.50 (verify IP/network)
├─ Check "paper" status
│  └─ If Out: Reload paper
└─ Run Test Printer → check if test receipt prints

Invoice not saving?
├─ Check disk space (du -sh ~/.config/sama-pharmacy/)
├─ Check file permissions (ls -la pharmacy.db)
├─ Check database isn't corrupted
│  └─ If corrupted: copy pharmacy.db-wal → pharmacy.db
└─ Restart the app (queue should replay)

🌟 HIGHLIGHTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. LAYOUT-SAFE SCANNER
   The scanner works correctly even when Windows is set to Arabic input
   language. Most pharmacy systems get this wrong.

2. ARABIC RECEIPT PRINTING
   Arabic text on thermal printers is notoriously difficult. This system
   renders receipts in Chromium and sends them as raster images, ensuring
   correct shaping, RTL layout, and ligatures on any ESC/POS device.

3. COMPREHENSIVE GUARDS
   15 separate guards catch silent failures (blank receipts, stuck
   keyboards, hung windows, truncated queues, etc.). Each is documented
   and monitored.

4. CRASH-SAFE PERSISTENCE
   Print queue survives app crashes. Database uses WAL mode. Invoices
   never get lost.

5. NO DRIVER INSTALLATION
   Scanner: USB HID keyboard-wedge (no driver)
   Printer: TCP 9100 or Windows share (no driver)
   Works on day 1.
